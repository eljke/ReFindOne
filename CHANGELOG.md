# ReFind One — изменения

## 0.3.0-beta.1 — 2026-10-20

Версия для проверки ежедневных сценариев на iPhone в LiveContainer.

- Новые коллекции: «Входящие», «Избранное», «Архив», «Всё». Новые материалы попадают во входящие. Избранное включает и архивные записи.
- Крупные кнопки добавления ссылки, заметки, фото и документа. Свайпы и контекстное меню для избранного, архива и удаления с подтверждением.
- Приём ссылок и файлов через «Поделиться → LiveContainer → ReFind One» в LiveContainer 3.8+. Ссылки открываются в форме подтверждения, файлы проходят штатную проверку импорта. Добавлен маршрут refindone://capture?text= для передачи текста.
- Поиск по началу слова, подсветка совпадений и фрагменты распознанного текста рядом с результатами. Тип материала сочетается с выбранной коллекцией.
- Загрузка записей порциями по 60 вместо ограничения библиотеки первыми 250 записями. Сортировка от новых к старым и обратно.
- Уменьшенные превью изображений. Фото и PDF открываются в системном просмотрщике с масштабированием.
- Сохранение правок больше не сбрасывает избранное или архив. Выход из изменённой карточки требует сохранить или отменить правки.
- Резервная копия проверяется целиком перед восстановлением. Добавление записей выполняется одной транзакцией; при ошибке новые вложения очищаются. Существующие записи сохраняются.
- Понятные статусы обработки, инструкция в настройках, дата последней сохранённой копии и ссылка на обновления.
- Версия задаётся в `VERSION`. Релизный тег запускает тесты, сборку IPA, публикацию GitHub Release и пакета в GHCR.

Перед обновлением экспортируйте коллекцию из версии 0.2. База автоматически переходит на схему v2, резервные копии JSON v1 поддерживаются. Для отката на приложение 0.2 нужен отдельный контейнер и импорт копии: приложение 0.2 не открывает базу v2.

Запуск в LiveContainer на физическом iPhone проверяется отдельно. Копии не зашифрованы. Сканированные PDF пока не распознаются; импорт файла ограничен 20 МБ, копии — 250 МБ. Формат JSON обрабатывается в памяти.
